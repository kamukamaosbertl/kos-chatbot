## ClariBox
An AI-powered, anonymous digital suggestion box. Students and staff submit anonymous feedback through a web and mobile platform, with optional image or PDF evidence; no identity is collected. A Node.js backend with a MongoDB database validates and stores feedback. An AI pipeline does sentiment analysis (positive, negative, neutral), emotion detection, FAISS vector search with embeddings, and categorising and summarising (academics, welfare, infrastructure). Administrators get secure login, a dashboard of trends, sentiments and emotions, report generation, an AI chat (RAG) to ask questions about the feedback, and analytics. Resolved issues feed a continuous learning loop that updates the FAISS index so answers improve over time.
Code: https://github.com/kamukamaosbertl/ClariBox-app
